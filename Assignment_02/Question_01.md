### Question 1

**Features of Python, Variables, Expressions, and Core Data Types**

#### Features of Python

* **Simple & Readable:** Clean, high-level syntax that reads like pseudo-code.
* **Interpreted Language:** Code is executed line-by-line, eliminating explicit compilation steps.
* **Dynamically Typed:** Variable data types are determined automatically at runtime without explicit declarations.
* **Multi-Paradigm:** Supports Procedural, Object-Oriented (OOP), and Functional programming styles.
* **Extensive Standard Library:** Built-in support for array manipulation, web interaction, file I/O, and data processing.

#### Variables & Expressions

* **Variable:** A named location in memory used to store a reference to data.
* **Expression:** A combination of variables, constants, operators, and function calls that evaluates to a single value (e.g., `result = (a + b) * 2`).

#### Core Data Types & Examples

```python
# Integer (int): Whole numbers without fractional parts
age = 21

# Float (float): Real numbers with decimal points
gpa = 8.75

# String (str): Ordered sequence of characters
name = "Gaurav"

# Boolean (bool): Truth values (True or False)
is_enrolled = True

# List (list): Ordered, mutable collection allowing duplicate elements
marks = [85, 90, 78]

# Tuple (tuple): Ordered, immutable collection allowing duplicate elements
coordinates = (30.3165, 78.0322)

# Set (set): Unordered collection of unique elements
unique_subjects = {"Python", "DBMS", "Networks"}

# Dictionary (dict): Key-value pairs with unique keys
student_info = {"roll_no": 101, "course": "BCA"}
```
